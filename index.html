¿Cómo obtener un Personal Access Token (PAT)?
  1. Ve a github.com/settings/tokens
  2. Pulsa "Generate new token (fine-grained)"
  3. Dale un nombre (ej: pesostrack) y selecciona Gists: Read and write
  4. Copia el token generado y pégalo abajo
